## Limites observados

- Muse Code 1.4.14 oferece execução headless e apresentou perfis para Muse Spark 1.3 e Muse Ember 1.0. As duas delegações Muse ficaram `BLOCKED_UNSUPPORTED_ADAPTER` no Hivemind P003.
- O conector da Vercel recebeu HTTP 403 na equipe da conta. O CLI local também não tinha credenciais. A publicação Vercel depende de autorização da equipe ou autenticação do CLI.
- O teste móvel usa eventos de toque CDP no Chrome com viewport de 320 × 700 CSS px. O resultado em Android físico fica pendente.

## Reprodução

```sh
npm ci
npm run build
npm run typecheck
npm run lint
npm test
npx playwright install chromium
npm run test:e2e
```

O Playwright inicia o servidor de preview do build local. Defina `PLAYWRIGHT_CHANNEL=chrome` para usar o Chrome instalado ou `TEST_BASE_URL` para validar uma implantação que já esteja acessível. Inclua a barra final ao testar uma URL sob um caminho.
