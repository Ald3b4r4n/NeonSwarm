# NEON SWARM

Arena survivor 2D, React/Canvas sem backend. WASD/setas e controle por ponteiro, disparo automático, três inimigos, vida, energia, três opções por nível, ondas, pausa, derrota, reinício e recorde local. Interface em português com layout até 320 CSS px. Motor puro em TypeScript, independente de DOM e React. Frontend e motor ficam em arquivos separados para desenvolvimento paralelo.
